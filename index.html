Automation

I also automate the busywork around a business: leads, follow-ups, reports and the hand-offs between tools that don't talk to each other.

n8n

Workflows that connect apps through webhooks and APIs. They move data between systems, trigger alerts, and run scheduled jobs with error handling so nothing fails silently.

GoHighLevel

CRM pipelines, lead capture, and automated SMS and email follow-ups. Workflows move contacts through each stage on their own, and integrations keep GHL in sync with the rest of the stack.

Python

Scripts and services for the jobs no-code tools can't handle: custom API integrations, data cleanup and imports, scheduled reports, and back-end endpoints that workflows can call.
